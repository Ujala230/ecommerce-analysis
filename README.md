## 📊 Power BI Dashboard

An interactive Power BI dashboard was created to analyze customer behavior, purchasing patterns, revenue performance, marketing channels, product categories, devices, payment methods, and ratings.

### Dashboard Features
- KPI cards for customers, purchases, revenue, purchase rate, and average time on site
- Customer type analysis
- Revenue by product category
- Marketing channel analysis
- Device-wise purchase analysis
- Payment method analysis
- Rating vs purchase analysis
- Pages viewed vs revenue analysis
- Interactive slicers for filtering the dashboard

## 📁 Project Files

- `Ecommerce.csv` — Dataset used for analysis
- `ecommerce_analysis.sql` — SQL queries and analysis
- `customer analysis.pbix` — Power BI dashboard
- `Dashboard.jpeg` — Dashboard preview
