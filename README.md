# 🛒 E-Commerce Sales & Customer Analysis | MySQL

## 📌 Project Overview

This project focuses on analyzing e-commerce sales and customer behavior using **MySQL**. The goal is to understand customer purchasing patterns, sales performance, product performance, and factors affecting conversions.

The project uses SQL queries to generate meaningful business insights from e-commerce customer and transaction data.

## 🎯 Objectives

* Analyze overall sales and revenue performance
* Understand customer purchasing behavior
* Identify repeat and one-time customers
* Segment customers based on revenue
* Analyze marketing channel performance
* Analyze product and category performance
* Measure purchase conversion and cart abandonment
* Identify top-performing customers and products
* Analyze payment methods, discounts, ratings, devices, and locations
